# 记忆科学：设计规则来源

本文件把「为什么这样设计」讲清楚，供 skill 在实现时对照。每个结论尽量给证据与研究来源。

## 1. 艾宾浩斯遗忘曲线

Hermann Ebbinghaus（1885）用无意义音节测得：遗忘不是线性的，学完立刻掉得最快，之后变缓。

不复现情况下的留存率（Murre & Dros 2015 复现了原始数字）：

| 学完后 | 留存率 |
|---|---|
| 20 分钟 | ~58% |
| 1 小时 | ~44% |
| 1 天 | ~34% |
| 2 天 | ~28% |
| 6 天 | ~25% |
| 1 个月 | ~21% |

**含义**：一个月不复习会丢掉约 80%；但每次「适时复习」会把曲线重置并拉平，4–5 次复习后留存回到 80–90%+，变成长期记忆。**第一次复习务必在 24 小时内。**

推荐排程（共识区间）：`D0 → +1 → +6 → +16 → +40 → +90` 天（见第 3 节 SM-2 实际生成值）。

## 2. 检索练习 > 重读（测试效应）

- Roediger & Karpicke（2006, *Psychological Science*）：一组读 4 遍（SSSS），另一组读 1 遍 + 做 3 次自由回忆（STTT），总时间相同。**1 周后测试组回忆 ~50–65%，重读组 ~40%**，差距随时间拉大。结论：「检索不只是测学习，检索本身造成学习。」
- Dunlosky 等（2013）元分析：把 10 种学习技术分出效用——**练习测试、分散练习 = 高效用**；重读、划线、摘要 = 低效用。
- Szpunar 等（2013）：重读的人会高估自己未来记忆 30–40%，测试的人校准准确（元认知收益）。

**设计落地**：默认学习模式是「检索」不是「复习」；永远先让用户尝试回忆，再揭晓答案并打分。

## 3. SM-2 算法（复习排程的可实现公式）

来源 P. Wozniak（1990）SM-2，仍是大多数间隔重复 App 的骨架。

每个条目状态：`EF`（易度因子）、`n`（连续答对次数）、`I`（当前间隔天数）。

初始化：`EF = 2.5`，`n = 0`，`I = 0`。

质量分 `q`（0–5，每次回忆后由学习者给）：5=完美，4=犹豫后正确，3=很费力才对，2=错了但一看就懂，1=错了但觉得眼熟，0=完全想不起来。

**更新公式**：

```
EF' = EF + (0.1 - (5 - q) * (0.08 + (5 - q) * 0.02))
if EF' < 1.3: EF' = 1.3        # EF_min = 1.3

if q < 3:
    n = 0
    I_next = 1                 # 失误：重置，1 天后重来
else:
    n = n + 1
    if   n == 1: I_next = 1    # I1 = 1
    elif n == 2: I_next = 6    # I2 = 6
    else:        I_next = round(I_prev * EF')   # I_n = I_{n-1} * EF (n>=3)
```

默认 `EF=2.5, q=5` 时生成的间隔序列：`1 → 6 → 16 → 40 → 100…` 天，正是第 1 节推荐的排程。

**设计落地**：复习计划区给每个概念一行，附 0–5 自评控件；打分后用上面公式即时重算「下次：+N 天」。不建账号、不跨会话持久化（本 skill 只做「理解 + 复习计划」，不做长期追踪系统）。

## 4. 费曼技巧

四步：①挑一个概念写下来；②用大白话讲给 12 岁小孩听，不用术语（或用了立刻简单重定义）；③标记每一个卡壳、想用术语糊弄、说「它就是这样的」的点——这些才是真·理解缺口；④只回去看缺口，再讲一遍，循环到讲得简单又完整。

**设计落地**：每张卡给「用自己的话讲一遍」提示；用大白话解释；术语首次出现立即简单重定义。

## 5. 双重编码（Paivio）+ 关键红线

大脑有两条独立表征系统：语言系统（文字）和非语言/意象系统（图、空间）。两者同时激活 → 同一概念存下两条带相互引用的记忆痕迹 → 两条检索路径，而非一条。具体词（狗、自行车）会自发唤起图像，记忆约 2 倍于抽象词（正义、理论）。

⚠ **冗余效应红线（Mayer 多媒体学习理论）**：加第三个通道没用，反而有害。当同一信息同时用「语音旁白 + 屏幕文字」呈现，两者抢唯一的语言通道 → 认知过载 → 学得更快。装饰性配图若只是重复文字、不提供第二条路径，也会加噪音伤记忆。

**设计落地**：每张卡配的图必须提供文字没有的结构 / 空间 / 关系信息（流程图、层级图、对比图、示意图），绝不能放装饰图，也不能把卡片文字改成图再念一遍。

## 6. 认知负荷理论（Sweller）

工作记忆极有限（~4 个新组块）；长期记忆近乎无限、存的是「图式」（打包好的知识块）。学习 = 把组织好的知识在不挤爆工作记忆门槛的前提下搬进长期记忆。

三类负荷：内在（材料本身复杂度，固定）、外在（差呈现制造的浪费，必须最小化）、关联（建图式的有效努力）。

**设计落地**：卡片版式干净、一卡一概念、图文整合不分裂注意力；流程类给 worked example（完整示范）再让用户自己来；随熟练度降低脚手架。

## 7. 精细化加工 & 分块

- Craik & Lockhart（1972）加工层次：记忆由加工深度决定，不是时间或遍数。深 / 语义 / 精细化加工 → 强痕迹。
- 精细化提问（「为什么是真的？」「这和我已知的有什么联系？」）是证据明确的有效形式。
- 分块（Miller 1956 / Cowan 2001）：把多个元素编成有意义的组块。例如 12 步流程拆成 3–4 个子目标；把清单变成有结构的脑图。

**设计落地**：提示用户问「为什么 / 怎么连到旧知」；多部分内容拆成少量带标签的组块，不堆成文字墙。

## 8. 故事 / 叙事记忆优势（具体数字）

- Bower & Clark（1969）：把单词编进故事的被试，120 词中位回忆 **93%**；死记对照组仅 **13%**。
- Heath & Aaker（斯坦福，见《Made to Stick》）：1 分钟演讲含约 2.5 个统计数字，10 分钟后听众记住 **63% 的故事**但只有 **5%** 的单个统计。
- 神经科学（Zak）：故事触发催产素与「叙事传输」，调动视觉 + 情绪 + 意象脑区，神经活动约为纯事实的 5 倍。

**设计落地**：每个抽象或清单式概念，都给一个具体小故事 / 类比（人物、冲突、解决），把干巴巴的事实裹进叙事，统计数字挂到具体的人 / 事上。

## 9. 生成效应 & 交错

- 生成效应（Slamecka & Graf 1978）：自己「生成」目标词的人，比只读的人记得牢，即使词完全相同。
- 交错（Rohrer & Taylor）：把不同题型混着练，比同题型块练，后续测试高 ~43%，虽然练的时候感觉更糟。因为交错逼你「辨别题型 + 选策略」，正是真实考试要的。

**设计落地**：优先用「生成答案」卡（填空、自己举例、排序），胜过选择 / 直接给答案；复习时混着练不同概念，不一个概念刷到底。

## 10. 15 条可落地设计规则

1. **一概念一卡**（原子化 / 最小信息原则）。
2. **每个概念配互补视觉**（图必须提供文字没有的结构 / 空间信息，禁装饰、禁文字复读）。
3. **揭晓前先强制主动回忆**（测试效应）。
4. **用 SM-2 扩展间隔排复习**（首次 ≤24h；之后 1→6→16→40…；`q<3` 重置）。
5. **每次回忆后给 0–5 质量分**（驱动调度 + 元认知校准）。
6. **每个抽象概念配故事 / 类比**（93% vs 13%；63% vs 5%）。
7. **清单 / 事实用口诀**（首字句、挂钩法、地点法）。
8. **连到旧知**（提示「这和你已知的什么有关？」）。
9. **费曼自述**（用自己的话、禁术语、标缺口、回源补）。
10. **最小化外在认知负荷**（干净版式、一概念、图文整合、无装饰、不语音+文字同说）。
11. **流程类给 worked example**（先完整示范，随熟练撤脚手架）。
12. **先用问题引导**（每张卡正面是 What/Why/How，制造合意困难）。
13. **复习时交错**（混练不同概念，不块练）。
14. **让学习者生成，不只接收**（填空、自己举例、排序）。
15. **用具体词 + 分块**（具体名词记忆约 2 倍；多步拆成 3–4 个带标签组块）。

**附加操作规则**：每次回忆尝试后立刻给反馈（揭晓答案 + 讲为什么）；失败检索 + 纠正比顺畅重读编码更强（合意困难 / 生产性失败，Bjork）。

## 11. 养成类附加规则（实证见 `references/gamification.md`）

游戏化把「坚持复习」这件反人性的事，变成「看得见自己变强」的正反馈循环——这是记忆留存最稀缺的连续性。但基于双重编码 / 认知负荷红线，勋章与等级**必须轻量、不抢知识注意力**。

16. **即时反馈 + 进度可视化**（XP / 等级 / 进度条把「遥远的掌握」切成「下一步就到」的小目标，目标梯度假说；每点 XP、每次解锁都给即时正反馈）。
17. **连续学习 streak**（损失厌恶驱动坚持——「断了就白练」比「想拿奖励」更有效；仅真实互动计入，避免只看不学刷天数）。
18. **勋章收集欲**（成就 / 进度类徽章提升任务投入；按材料主题做**定制勋章**增强语境代入感，如荣誉材料「荣誉满墙」、前端「DOM 驯服者」；但一旦弹窗轰炸 / 花哨动效就违反最小外在负荷）。
