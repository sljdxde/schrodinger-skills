# 荣誉体系（Gamification v2）

让学习包不只是「资料」，而是一个**有进度、有反馈、有收集欲、有成长感**的养成空间。v2 引入 RPG 式属性、连击系统、勋章阶位和里程碑奖励——参考 Roguelike/卡牌养成类游戏的成长曲线设计。

## 1. 为什么做（游戏化对动机与坚持的实证）

- **徽章（badges）提升参与**：Hämäläinen & Vincent（2017）综述指出，徽章对**成就与进度**信号最有效。
- **连续学习（streak）利用损失厌恶**：Duolingo 留存神话的核心。
- **即时反馈 + 目标梯度效应**：Hull 的目标梯度假说——进度条越接近满，人越快行动。
- **等级称号制造身份认同**：自我知觉理论——代入感提升投入。
- **⭐ v2 新增：属性系统让成长可见**：RPG 六维雷达让「我变强了」不再抽象，每个动作都有对应维度在涨。
- **⭐ v2 新增：连击系统制造心流**：连续答对的正向反馈循环（参考音游/卡牌 combo 机制），提升答题沉浸感。
- **⭐ v2 新增：勋章阶位（铜/银/金/钻石）**：分层成就感，避免「拿了就没感觉」。

⚠ **红线**：游戏化是**辅助**，不能喧宾夺主挤占认知资源。勋章墙、等级条必须轻量、不抢知识卡片的注意力。

## 2. 等级体系 v2（15 级指数曲线）

### 设计理念（Roguelike 启发）

| 阶段 | 等级范围 | 定位 | 体验目标 |
|---|---|---|---|
| 学徒期 | Lv.1–4 | 新手保护 | <30 分钟可达 Lv.3，快速正反馈 |
| **突破点** | **Lv.5** | **解锁属性面板** | **里程碑：「小有所成」+ 六维雷达可见** |
| 进阶期 | Lv.6–9 | 持续投入 | 需要完成大部分内容才能到达 |
| **大成点** | **Lv.10** | **解锁连击系统** | **里程碑：「登堂入室」+ XP 加成** |
| 大师期 | Lv.11–14 | 深度用户 | 需要复习 + 反复使用才能升到 |
| **传说点** | **Lv.15** | **满级传奇** | **里程碑：「至圣先师」+ 终极成就** |

## 3. 经验规则 v2（带属性标签）

每类行为给不同属性加成，同时获得 XP：

| 行为 | 基础 XP | 关联属性 | 属性单次加成 |
|---|---|---|---|
| 翻转一张卡（首次） | +3 | 记忆力 (MEM) | +1 |
| 自测答对 | +12 | 洞察力 (INS) | +2 |
| 自测答错（鼓励分） | +3 | 洞察力 (INS) | +1 |
| 复习自评一次 | +10 | 韧性 (RES) | +1 |
| 完成费曼自述勾选 | +8 | 表达力 (EXP) | +1 |

> 连击激活后（Lv.10+），答对 XP 会乘以连击倍率（最高 2x）。

## 4. ⭐ 六维属性系统（RPG Stat Radar）

### 属性设计

| ID | 名称 | 图标 | 颜色 | 描述 | 主要来源 |
|---|---|---|---|---|---|
| MEM | 记忆力 | layers | #64B5F6 | 卡片翻转积累 | 翻卡 |
| INS | 洞察力 | target | #FF8A65 | 自测答题积累 | 答题（对/错） |
| RES | 韧性 | shield | #81C784 | 复习坚持积累 | 复习评分 |
| EXP | 表达力 | pen-line | #BA68C8 | 费曼复述积累 | 费曼勾选 |
| CUR | 探索力 | compass | #4DD0E1 | 联网深潜积累 | 含 web_source 的概念 |
| FOC | 专注度 | flame | #FFB74D | 连续学习积累 | daily streak |

### 规则

- 每个属性值范围 **0–100**，归一化显示
- **Lv.5 解锁**属性面板显示（之前隐藏）
- 属性只增不减（同一会话内），作为「努力可视化」信号
- 重置进度时清零
- UI 以横向进度条 + 数值展示，颜色对应各属性主题色

### 设计灵感

借鉴 **Roguelike 游戏（如 Hades/Dead Cells）的 Meta-progression**：
- 不是战力数值，而是「你在这个知识领域投入了多少」的可视化
- 六维雷达让学习者一眼看出自己的「学习类型」（记忆型 vs 理解型 vs 实践型）
- 每个维度独立，避免单一指标焦虑

## 5. ⭐ 连击系统（Combo）

### 规则

| 配置项 | 默认值 | 说明 |
|---|---|---|
| 解锁等级 | Lv.10 | 未达等级时连击计数但不生效 |
| 倍率表 | [1x, 1.3x, 1.6x, 2x] | 0/1/2/3+ 连击对应的 XP 倍率 |
| 最大连击 | 99 | 显示上限 |
| 答错断连 | 是 | 答错归零（可配置不断） |

### UX 设计

- 连击计数器在荣誉墙统计区显示（默认隐藏，Lv.10 后出现）
- ≥3 连击时高亮动画（脉冲效果）
- 每次答错有明确视觉反馈（连击归零）
- 连击记录 `comboMax`（本次会话历史最高）用于触发连击勋章

### 设计灵感

参考 **音游（osu!/Arcaea）和卡牌游戏（Slay the Spire）的 Combo 机制**：
- 连击创造「不想停下来」的心流状态
- 答错的惩罚性（断连）比奖励性更有驱动力（损失厌恶）
- 2x 上限防止 XP 膨胀失衡

### 特殊勋章逻辑

- **perfect_run**：一轮内全部操作零失误（全部答对 + 所有复评 ≥4 分）。这是最难获得的勋章之一，对标 Roguelike 的「无伤通关」成就。
- **speed_run**：从打开页面到完成所有卡片翻转 + 自测 ≤ 10 分钟。鼓励一气呵成的深度学习模式。
- **combo5/combo10**：连击系统的配套成就，给连击玩法一个长期目标。

## 7. 里程碑通知（Milestone Toasts）

当等级达到 5/10/15 时，除了普通升级 toast 外，还会显示特殊的**里程碑消息**：

| 等级 | 里程碑消息 | 效果 |
|---|---|---|
| Lv.5 | 「突破！解锁属性面板——从此可见六维成长雷达」 | 属性面板从隐藏变为可见 |
| Lv.10 | 「大成！解锁连击系统——连续答对触发 XP 加成」 | 连击计数器显示并开始生效 |
| Lv.15 | 「传说！满级达成——你已是知识殿堂的传奇人物」 | 终极庆祝（无更多解锁） |

里程碑 toast 使用特殊样式（渐变背景 + 更大尺寸），与其他 toast 区分。

## 8. 连续学习（streak）逻辑（不变）

- 状态存浏览器本地（localStorage，按学习包隔离）。
- 每天**首次互动**记一次：昨天 → +1；今天已记 → 不变；断 ≥2 天 → 重置。
- 仅「真实互动」才计 streak。

## 9. Agent 如何定制 v2

```json
"gamification": {
  "levels": [ {"level":1,"title":"初心学徒","min_xp":0,"phase":"apprentice","color":"#9E9E9E"}, ... ],
  "xp_rules": {
    "flip_card":    {"xp": 3,  "attr": "MEM", "label": "记忆"},
    "quiz_correct": {"xp": 12, "attr": "INS", "label": "洞察"},
    "quiz_wrong":   {"xp": 3,  "attr": "INS", "label": "洞察"},
    "review_rate":  {"xp": 10, "attr": "RES", "label": "韧性"},
    "feynman_done": {"xp": 8,  "attr": "EXP", "label": "表达"}
  },
  "attributes": [
    {"id":"MEM","name":"记忆力","icon":"layers","desc":"翻转卡片积累","color":"#64B5F6"},
    ...
  ],
  "combo": { "enabled_at_level": 10, "multipliers": [1,1.3,1.6,2], "max_combo": 99 },
  "badges": [ ... ],
  "tier_names": {1:"铜", 2:"银", 3:"金", 4:"钻石"}
}
```

### 向后兼容

- 不提供 `gamification` 或只提供旧格式（plain number xp_rules）→ 自动升级到 v2 结构
- 旧格式 payload 生成的学习包仍可正常加载（JS 引擎兼容两种格式）
- `xp_rules` 支持 `{xp: N, attr: "KEY", label: "名"}` 对象或纯数字 `N`

## 10. 实现约束（不变）

- 全部逻辑在 `build_package.py` 内联进 HTML（CSS/JS 全内联，无 CDN）。
- 进度存 `localStorage`，作用域是「这一个学习包文件」。
- 若禁用 localStorage 则降级为仅当次会话有效。
