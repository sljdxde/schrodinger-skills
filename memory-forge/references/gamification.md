# 荣誉体系（Gamification）

让学习包不只是「资料」，而是一个**有进度、有反馈、有收集欲**的养成空间。人在「看得见自己变强」时更有动力坚持——这正是记忆留存最稀缺的东西（复习的持续性）。本文件规定勋章、等级、经验、连续学习（streak）的设计与解锁逻辑，供 `build_package.py` 渲染、Agent 在生成时定制。

## 1. 为什么做（游戏化对动机与坚持的实证）

- **徽章（badges）提升参与**：Hämäläinen & Vincent（2017，*Educational Psychologist*）综述指出，徽章在「状态/成就/进度」三类里对**成就与进度**信号最有效，能显著提升任务投入与坚持。本质是给抽象进步一个**可见、可收藏**的锚点。
- **连续学习（streak）利用损失厌恶**：连续天数一旦断了「就白练了」的心理，是 Duolingo 等留存神话的核心（streak 让日活留存高出数倍）。这是行为经济学「损失厌恶」的直接应用——人更怕失去已有的，而非想获得新的。
- **即时反馈 + 目标梯度效应（goal-gradient）**：进度条越接近满，人越快行动（Hull 的目标梯度假说；Kivetz 等用在奖励计划）。每一点 XP、每一次解锁，都把「遥远的掌握」切成「下一步就到」的小目标。
- **等级称号制造身份认同**：「满腹经纶」「博学鸿儒」这类称号给用户一个可代入的「学习者身份」，代入感本身提升投入（自我知觉理论）。

⚠ **红线**：游戏化是**辅助**，不能喧宾夺主挤占认知资源（见双重编码/认知负荷）。勋章墙、等级条必须轻量、不抢知识卡片的注意力；一旦变成弹窗轰炸或花哨动效，就违反了「最小化外在负荷」原则。

## 2. 等级体系（默认）

经验（XP）累积升级，称号制造身份。默认阈值（Agent 可在 `payload.gamification.levels` 覆盖）：

| 等级 | 称号 | 所需累计 XP |
|---|---|---|
| 1 | 初心学徒 | 0 |
| 2 | 识字书生 | 50 |
| 3 | 博闻少年 | 130 |
| 4 | 通晓学子 | 260 |
| 5 | 满腹经纶 | 450 |
| 6 | 博学鸿儒 | 700 |
| 7 | 融会宗师 | 1000 |

## 3. 经验规则（默认）

| 行为 | 获得 XP |
|---|---|
| 翻转一张卡（首次） | +3 |
| 自测答对 | +12 |
| 自测答错（仍给鼓励分） | +3 |
| 复习自评一次 | +10 |
| 完成一次费曼自述勾选 | +8 |

> 答错也给分，避免「怕错就不练」——生产性失败（Bjork）比顺畅重读编码更强，要鼓励尝试。

## 4. 勋章集（默认 trigger 枚举）

每个勋章：`id` / `name` / `icon`（emoji 或内联 SVG）/ `desc` / `trigger`（解锁条件标识）。

| id | 名称 | 图标 | trigger | 解锁条件 |
|---|---|---|---|---|
| `first_pack` | 启程 | 🌱 | `on_generate` | 打开学习包即得 |
| `first_quiz` | 破冰 | ❄️ | `quiz_correct_first` | 首次答对自测 |
| `all_quiz` | 火眼金睛 | 🎯 | `quiz_all_correct` | 本包自测全对 |
| `first_review` | 温故知新 | 🌅 | `review_rate_first` | 首次复习自评 |
| `iron_will` | 百炼成钢 | 🛡️ | `review_count>=10` | 复习自评累计 10 次 |
| `master_all` | 融会贯通 | 🏆 | `all_review_ge4` | 所有概念自评 ≥4 |
| `feynman_master` | 费曼小能手 | ✍️ | `feynman_all` | 完成全部费曼自述 |
| `streak3` | 三日之约 | 🔥 | `streak>=3` | 连续 3 天学习 |
| `streak7` | 一周不辍 | 🌟 | `streak>=7` | 连续 7 天学习 |
| `level5` | 满腹经纶 | 📜 | `level>=5` | 等级达到「满腹经纶」 |
| `knowledge_hunter` | 知识猎人 | 🧭 | `web_deepdive>=1` | 包内含联网深潜讲解 |

`trigger` 阈值类用 `<key>>=N` 形式（`review_count`、`streak`、`level`），脚本解析。解锁时弹 toast + 勋章墙点亮（彩色）；未解锁灰显 + 悬停显示「如何获得」。

## 5. 连续学习（streak）逻辑

- 状态存浏览器本地（localStorage，按学习包隔离）。
- 每天**首次互动**（翻卡/自测/复习/费曼）记一次：若上一次学习是昨天 → streak+1；若今天已记过 → 不变；若间隔 ≥2 天 → 重置为 1（「断了从头来」的损失厌恶驱动力在此生效）。
- 仅「真实互动」才计 streak，避免只看不学刷天数。

## 6. Agent 如何定制

`payload.gamification` 可选。不提供时用上面的默认集。提供时：

```json
"gamification": {
  "levels": [ {"level":1,"title":"初心学徒","min_xp":0}, ... ],
  "xp_rules": { "flip_card":3, "quiz_correct":12, "quiz_wrong":3, "review_rate":10, "feynman_done":8 },
  "badges": [
    { "id":"honor_wall","name":"荣誉满墙","icon":"🏅",
      "desc":"通览了中心的荣誉与资质全貌","trigger":"on_generate" }
  ]
}
```

- Agent 可**按材料主题加定制勋章**（如荣誉材料加「荣誉满墙」、前端材料加「DOM 驯服者」），让收集更有语境代入感。
- 脚本会**自动剔除不可能获得的勋章**：包内无联网深潜概念则不显示 `knowledge_hunter`；无费曼卡片则不显示 `feynman_master`；无自测则不显示 `all_quiz`。保持勋章墙「每一枚都拿得到」。

## 7. 实现约束（与 skill 离线定位一致）

- 全部逻辑在 `build_package.py` 内联进 HTML（CSS/JS 全内联，无 CDN）。
- 进度存 `localStorage`，**作用域是「这一个学习包文件」**：同一份 HTML 反复打开进度保留；跨文件/跨设备不共享（本 skill 不做账号与云端，符合「理解 + 复习计划」定位）。
- 若用户浏览器禁用 localStorage，则勋章墙仍展示、互动仍可得 XP 显示，只是不持久（优雅降级）。
