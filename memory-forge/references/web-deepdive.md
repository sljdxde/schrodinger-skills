# 联网深度讲解（web-deepdive）

当材料里的术语用户显然不熟、或材料只丢了个名词没解释时，skill 应主动去网上找权威解释 + 图，再浓缩进卡片。本文件规定什么时候去、去哪找、怎么处理。

## 1. 触发条件（满足任一即深潜）

- 概念在材料里**只出现名词、没有解释**（如「发改大脑」「无感监测」「碳账户碳金融」）。
- 概念**跨领域**：材料是 A 领域却冒出 B 领域专有词，且不属于用户受众的常识。
- 用户**口头说不懂**：「这个我不懂」「讲讲 X 是什么」。
- 需要**配图**但 Agent 自己画不准（如某种标准架构图、官方流程图）→ 取官方图改内联。

不触发：材料已讲清、或属于常识 / 用户领域内的词 → 直接锻造，别浪费联网。

## 2. 怎么联网（用 web-access skill）

本仓库已装 `web-access` skill（真实浏览器 / 网页抓取 / 搜索）。调用方式：用自然语言让 Agent「用 web-access 打开 MDN 的 DOM 页面，抓取定义和 DOM 树示意图」。若 web-access 不可用，退回 `WebFetch` / `WebSearch` 工具。

流程：
1. 先搜「概念名 + 定义 / 官方文档 / diagram」。
2. 优先进**官方/权威站**（见第 3 节）。
3. 抓：一句话定义、1–2 个关键点、一张结构/流程示意图。
4. 把图**转成内联 SVG**（手绘简化版或 ImageGen 重绘），不要外链图片（破坏离线）。
5. 浓缩进卡片 `card_back` / `plain` / `visual`，并在 `web_source` 写清出处 + 获取日期。

## 3. 可信源优先级

| 等级 | 来源 | 例子 |
|---|---|---|
| 高 | 官方文档、标准组织、政府/机构站、Wikipedia 词条 | MDN、W3C、IEEE、国家统计局、gov.cn |
| 中 | 主流技术博客、知名大学课件、权威媒体 | 各厂技术博客、大学 OCW |
| 低 | 自媒体、论坛、未标来源榜单 | 不单独支撑，仅作线索 |

低可信源只能当线索，不能单独进卡片；涉及政策 / 数据必须优先官方口径。

## 4. 图转内联 SVG

- 优先**手绘简化 SVG**（节点 + 连线 + 标签），保证离线、可控、和文字互补。
- 若概念适合且环境允许，可用 `ImageGen` 重绘一张示意图，再内联 base64（注意体积）。
- 绝对**不要** `<img src="https://...">` 外链——这会破坏离线学习包，且可能失效。
- SVG 里文字用 `<text>`，标签靠近它所标注的部件（Mayer 邻近原则）。

## 5. 标来源 + 日期（强制）

联网补充的内容，卡片里必须有来源标注，格式：

```
web_source: "来源：MDN Web Docs《DOM》；获取：2026-08-01"
```

并在卡片视觉/背面角落显示，让用户知道「这句是网上查的，不是原材料里的」。不编造；查不到就写「未查到权威公开解释」。

## 6. 深潜也要遵循记忆规则

联网来的解释同样是「给用户的记忆辅助」，必须满足：大白话、配互补图、先问题后答案、给自测。别把官方长文直接贴卡上。
