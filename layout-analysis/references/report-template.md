# Report Template — 完整报告结构

报告开头 5 行内给出**总评一句话**（如「整体方正、采光好，但次卧偏小、无独立储物」），再展开。

## 输出纪律

- 所有尺寸/面积标注来源；图片没标的写「待确认」，不补经验值。
- 评分必须每维附依据，与 dimension-checklist.md 的锚点一致。
- 「不构成房价/投资建议」结尾固定提示。
- 有横向对比需求时，加「与其他户型对比」小节（同小区同面积段 2–3 个）。
