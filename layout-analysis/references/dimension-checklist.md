# Dimension Checklist — 五大分析维度与评分锚点

每个维度 0–5 分。给分必须附「一句依据」，不允许只打分不说明。

## 1. 空间利用 (Space Utilization)

判断标准：
- 功能分区是否清晰（动静分区：客厅/餐厅/厨房 vs 卧室；干湿分区：卫生间淋浴 vs 洗漱）。
- 面积浪费点：纯过道面积占比（一般 ≤8% 为佳）、大而无当的玄关/走廊、鸡肋空间。
- 收纳潜力：是否有独立储物/衣帽间、玄关柜位、厨房/卫生间收纳位。
- 房间尺寸比例：主卧面宽是否 ≥3.3m、客厅面宽是否 ≥3.6m（参考值，非绝对）。

| 分数 | 锚点 |
|---|---|
| 5 | 分区极清晰，几乎零浪费，收纳充足 |
| 3 | 分区基本合理，有 1 处明显浪费 |
| 1 | 动线/分区混乱，浪费严重 |

## 2. 动线 (Layout Flow)

三类动线：
- **居住动线**：入户 → 玄关 → 客厅 → 卧室 → 卫生间，不穿越他人休息区。
- **家务动线**：厨房 → 餐厅 → 洗衣/晾晒，厨房操作三角（水槽-灶-冰箱）顺畅。
- **访客动线**：卫生间与客厅位置是否避免「客人路过卧室」。

判断要点：动线是否交叉冲突、是否要穿过卧室才能到卫生间、厨卫距离是否过远。

## 3. 采光通风朝向 (Orientation / Light / Ventilation)

- 朝向优先：南向主卧/客厅为佳；纯北向卧室冬季阴冷扣分。
- 开窗面：客厅开窗面宽、卧室窗墙比、是否全明（厨卫有外窗）。
- 采光深度：进深过大（>14m）中间区域暗；暗卫暗厨标注。
- 通风路径：是否南北/东西通透（对流通风）；单面通风扣分。
- 噪音与隐私：临路/临电梯井/临垃圾房的位置。

## 4. 私密性 (Privacy)

- 卧室门是否正对入户门/客厅。
- 主卧是否紧邻公共卫生间或厨房。
- 阳台/窗户是否正对邻居楼体（楼间距过近）。

## 5. 改造潜力 (Renovation Potential)

- 可拆改空间：非承重墙数量、可合并的房间（如客厅+阳台、小次卧+主卧）。
- 结构限制：承重墙/剪力墙/梁位/管井位置（图中粗黑实线通常为承重墙，不可拆）。
- 特殊加分：设备平台/飘窗/赠送面积的可利用性。

## 综合评分

加权建议：空间利用 30% / 动线 20% / 采光通风 25% / 私密性 10% / 改造潜力 15%。总分 = Σ(维度分 × 权重)，保留 1 位小数。

## 适用人群判断

- **自住刚需**：重功能分区与收纳，90-110㎡ 小三房常见痛点（次卧过小、暗卫）。
- **改善置换**：重面宽、主卧套房、双卫、动静分区。
- **投资**：重户型流通性（主流户型 vs 异形）、出租便利（独立厨卫、房间数）。
