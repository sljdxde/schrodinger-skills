# Renovation Feasibility — 改造可行性判断

改造建议必须说明**可行性**，拿不准就标注「需现场确认 / 需查竣工图」。原则：结构安全优先，不做承重墙拆改建议的模糊化处理。

## 可拆性判断线索（按户型图）

| 图面线索 | 判断 |
|---|---|
| 粗黑实线墙 / 加粗墙体 | 大概率承重墙/剪力墙，**不可拆**，只做开口需结构评估 |
| 细线墙 / 虚线墙 | 大概率非承重隔墙，可拆改（仍需物业确认） |
| 飘窗/设备平台/阳台围挡 | 改造需看物权与物业规定，阳台封包各地政策不同 |
| 管井/烟道/立管位置 | 不可移动，影响厨房卫生间改造边界 |

## 常见改造手法

- **客厅+阳台打通**：需确认阳台墙垛是否承重；非承重可扩采光与空间感。
- **小次卧并入主卧**：做套房（衣帽间/书房），仅限非承重隔墙。
- **厨房开放化/半开放**：注意燃气规范（多数城市开放式厨房需装报警器/隔断）。
- **卫生间干湿分离**：扩墙/移门需避让立管，注意防水重做成本。
- **增加收纳**：玄关柜、飘窗改造、床下收纳——几乎无结构风险。

## 风险标注模板

- 每条例外：`[需现场确认]` 或 `[需查竣工图/物业报备]` 后缀。
- 涉及承重的表述：`不建议拆改，如必须开口请结构工程师评估`。
- 成本提示：只给「量级」不给报价（拆墙/防水/封窗等量级描述），报价属边界外。

## 纪律

- 永远不给出「拆承重墙」的直接建议。
- 用户是租客时，标注「需业主同意」。
- 阳台封包、燃气改造等涉规事项，提示「以当地物业与燃气公司规定为准」。
