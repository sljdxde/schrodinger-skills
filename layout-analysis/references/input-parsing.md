# Input Parsing — 三通道输入解析

户型分析的第一步是把房源信息落成**结构化数据**。三通道优先级：网页链接 > 户型图图片 > 手动字段；有链接优先抓链接，没有就退图片/手填，信息不足先追问。

## 通道 1：网页链接抓取

支持贝壳（ke.com）、安居客、链家等网页版房源页。

- 抓取关键字段：小区名、楼栋/单元/楼层、户型（几室几厅几卫）、建筑面积/套内面积、朝向、楼层数、建成年代、物业类型。
- 优先找「户型图」图片 URL 与「户型详情」文本；户型图为图片时转入通道 2 读图。
- 页面有反爬（验证码/风控）时：不破解，改用浏览器化请求或让用户提供户型图截图/手填字段。

## 通道 2：户型图图片解析

读户型图时提取：

- 房间清单：每个房间的名称（主卧/次卧/客厅/餐厅/厨房/卫生间/阳台/储物间）。
- 尺寸线索：图中标注的尺寸（如 3.6m × 4.2m）、比例尺、房间面积标注。
- 结构线索：承重墙/剪力墙（通常粗黑实线）、飘窗/设备平台、门洞位置、开窗位置与朝向箭头。
- 朝向：图上的指北针或户型朝向说明。

读图纪律：图中没有的信息不猜；尺寸缺失时标注「待确认」，不按经验值补。

## 通道 3：手动字段

用户没有链接也没有图时，问清以下最小集（缺则追问）：

| 字段 | 必填 | 示例 |
|---|---|---|
| 户型 | 是 | 3室2厅1卫 |
| 建筑面积 / 套内面积 | 是 | 89㎡ / 72㎡ |
| 朝向 | 是 | 南 |
| 楼层 / 总层数 | 否 | 12/18 |
| 各房间面积或尺寸 | 否 | 主卧 15㎡…… |
| 建成年代 / 小区 | 否 | 2015，XX小区 |

## 追问纪律

- 户型、面积、朝向三者缺失时先追问，不分析。
- 一次最多追问一轮（≤8 问）；其他缺口标注为「假设」并在报告里说明。
