# CONTEXT.md — house-buying skill 领域词汇表

本文件只定义术语（通用语言），不含实现细节。实现决策见 `docs/adr/`。

## 术语

- **城市声明 (City Declaration)**：用户显式指定目标城市。skill 面向全国房源，不再默认杭州。所有检索式、数据源配置、报告口径均按声明城市解析；未内置源的城市回退到全国网页源 + 联网检索。

- **首付比例 (Down Payment Ratio)**：用户自行填写的**实际**首付百分比（如 30%），为 intake 必填字段。替代原"首套/二套"问题，用于计算所需现金、月供与购买可行性。可选附带"月供上限 / 贷款额度"。

- **价格时间轴 (Price Timeline)**：同一小区按 `YYYY-MM` 月度粒度记录的挂牌价 / 成交价 / 样本量序列。是趋势判断的强制证据，禁止用单一"当前均价"代替。

- **走势图 (Trend Chart)**：由时间轴数据生成的双序列折线图（挂牌均价 vs 成交均价，可选叠加成交量）。自包含 SVG，无外部依赖，内嵌报告；实时预览另给 Chart.js 版 HTML。

- **数据源通道 (Source Channel)**：取数三条路径——（1）抓包 API、（2）浏览器渲染（Playwright 兜底）、（3）联网检索兜底。依次降级。

- **本地小程序源 (Local Mini-program Source)**：城市封闭生态（微信小程序）房源源，如杭州「杭房数研」「小鸡选房」。取数需用户抓包拿到 endpoint + token，无法全自动。

- **政府公开源 (Government Open Source)**：各地住建 / 网签 / 二手房公示平台，多为无需登录的公开数据，是合规优先源。

- **政务 APP (Gov Service App)**：省级政务服务 App（如浙里办 / 随申办 / 粤省事 / 苏服办 / 皖事通），含不动产 / 住房板块，属封闭生态，仅作检索提示 + 授权后抓包。

- **城市源注册表 (City Source Registry)**：预置全国省会 + 自治区首府 + 直辖市（约 31 城）每城的推荐信息源清单（全国网页源 + 政府公开源 + 政务 APP + 本地小程序）。写入 `scripts/city_sources.json`，脚本按声明城市自动选源，避免运行时检索。

- **回迁房 / 商品房 (Resettlement / Commodity)**：学区房对口小区须区分。回迁房单价低、流动性弱，学区溢价计算须剔除，单独标注。

- **学区溢价率 (School Premium Rate)**：（学区商品房均价 − 周边非学区均价）/ 周边非学区均价。须基于完整学区小区集（非预算过滤子集）计算。
