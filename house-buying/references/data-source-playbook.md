# Data Source Playbook

本文件用于执行购房分析的数据采集。采集时优先找原始来源，多源交叉验证，最后用证据台账承载不确定性。

## 证据台账

每条关键结论都用这 6 列自查：

| 字段 | 写法 |
|---|---|
| 事实/数据 | 例如“近一年主力成交单价约 X 万/㎡” |
| 来源 | 网站、机构、文件名或平台 |
| 时间 | 发布日期或访问日期 |
| 适用范围 | 城市、片区、楼盘、户型、年份 |
| 置信度 | 高/中/低 |
| 备注 | 样本量、口径差异、是否挂牌价 |

## 数据源优先级

1. 政府与官方：统计局、教育局、住建局、规划资源局、民政/街道公开信息、学校官网或公众号。
2. **微信小程序（杭州高频，挂盘/成交主力）**：`杭房数研`、`小鸡选房`——杭州二手房**挂牌价与成交价的高频核心源**，必须优先拉取（取数机制见下）。
3. 交易与市场：贝壳/链家成交、安居客、房天下、诸葛找房、克而瑞、中指研究院、本地网签平台。
4. 地理与配套：高德/百度地图、地铁官网、医院/商圈/公园官方信息。
5. 舆情与口碑：主流媒体、自媒体、论坛、问答、业主讨论。只能做辅助线索。

### 微信小程序数据源（杭州挂盘价/成交价核心）

这两个是微信小程序封闭生态，**没有公开网页 API**，是杭州本地最准确的挂牌价/成交价来源之一，分析杭州二手房时必须优先纳入。

| 数据源 | 提供什么 | 可信度 | 取数机制 |
|---|---|---|---|
| **杭房数研**（也叫"杭房数据小程序"） | 杭州每日新房/二手房签约数据、各小区**成交价**、一年内量价走势；挂牌+成交双口径，日更高频 | 中-高（接近网签口径，但部分做低） | 抓包 API（推荐）或联网检索兜底 |
| **小鸡选房** | 杭州二手房**挂盘价主力**：板块/小区维度挂盘量、挂牌单价、带看、近期成交、小区画像 | 中（挂盘价反映卖方预期，需结合成交校验） | 抓包 API（推荐）或联网检索兜底 |

**取数机制（两种通道，详见 `school-district-workflow.md`）**：

- **抓包 API（推荐，数据最稳）**：在手机用 mitmproxy / Charles 对微信抓包，拿到小程序调用后端时的 `endpoint` 和登录态 `token`，填入 `scripts/sources.json`（参考 `scripts/sources.example.json`）。`scripts/data_sources.py` 即可脚本化直拉结构化挂盘/成交数据。抓包一次、长期复用。
- **联网检索兜底（默认）**：未配置接口时，`data_sources.py` 生成精确到小程序名的检索式（如 `杭房数研 文鼎苑 成交价`、`小鸡选房 文鼎苑 挂牌价`），由 AI 代理用 WebSearch / WebFetch 取数后回填。

> 无论哪种通道，取数后都要在证据台账标注来源、获取时间、口径（挂牌/成交）、样本量；把低可信口碑和高可信官方/小程序数据分开使用。

脚本调用示例：

```bash
# 拉取单个小区（已配 sources.json 走 API，否则输出检索式）
python scripts/data_sources.py fetch --source 杭房数研 --community 文鼎苑 --district 西湖
python scripts/data_sources.py fetch --source 小鸡选房 --community 文鼎苑 --district 西湖
```

## 搜索关键词

### 楼盘和交易

- `{城市} {小区名} 成交价`
- `{城市} {小区名} 贝壳 成交`
- `{小区名} 挂牌价 成交价`
- `{片区名} 二手房 成交量 均价`
- `{小区名} 房价 走势图`
- `{城市} 二手房 网签 月报`

### 微信小程序（杭州挂盘/成交核心源，必须优先）

- `杭房数研 {城市} {小区名} 成交价`
- `杭房数研 {城市} {小区名} 挂牌价 均价`
- `杭房数研 {城市} {小区名} 一年 量价走势`
- `小鸡选房 {城市} {小区名} 挂牌价`
- `小鸡选房 {城市} {小区名} 成交价 近期`
- `小鸡选房 {城市} {小区名} 挂牌量 带看`

> 这些检索式也可由 `python scripts/data_sources.py` 自动生成（见 `school-district-workflow.md`）。

### 政策和城市基本面

- `{城市} 统计公报 常住人口 出生率`
- `{城市} 住宅用地 供应 规划`
- `{城市} 限购 限贷 公积金 最新`
- `{城市} 二手房 成交量 月报`

### 可比样本

可比楼盘至少满足 2 个条件：

- 同城市同板块，或通勤/学校诉求相近。
- 总价带相近。
- 建成年代、产品类型、居住品质接近。
- 同一学校梯队或教育预期相近。

不要拿“纯学区老破小”和“品质改善次新房”直接比单价；必须拆成教育溢价、居住价值、流动性三个维度解释。

### 学区溢价样本

涉及学区房时，还必须按 `school-premium-comparison.md` 选择 2-3 个周边非学区或弱学区可比盘，用于估算目标房源相对普通居住价值的教育溢价。不要只做同学区内部小区比较。

## 数据处理规则

- 成交价优先于挂牌价；挂牌价只能反映卖方预期。
- 样本少于 5 套时，不要给精确均价，只给区间和样本说明。
- 同一小区必须按面积段、楼层、装修和户型拆分；学区房常见小户型单价高于大户型。
- 近 3 个月数据适合判断热度，近 12-36 个月适合判断趋势。
- 遇到平台数据冲突时，列出口径差异，不强行合并成一个数字。

## 输出前检查

- 是否标注了所有核心价格的来源和时间？
- 是否区分了成交、挂牌、网签、评估和传闻？
- 是否说明样本量和户型面积段？
- 是否有 2-3 个真正可比对象？
- 如果是学区房，是否有周边非学区/弱学区可比盘和溢价率解释？
- 是否把低可信口碑和高可信官方数据分开使用？
