# School Cohort Analysis（生源代际传导分析）

本文件回答一个关键问题：**如果我现在买学区房、孩子未来入学，目标学校的升学率会是什么样？**

核心洞察：**升学率是滞后 9-15 年的「生源成绩单」**——某年初中的重高率/优高率，反映的不是现在的孩子，而是约 9-15 年前出生、数年前入学的那批生源。直接用今天的数据预测未来，方法论上是错的。必须做**生源代际传导分析**：重建历史生源 → 对比当前生源 → 预测未来升学表现。

---

## 一、时间线推演（出生 → 中考的传导链）

```
出生年 A
   ↓ 满 6 岁（A+6）
小学一年级入学（A+6）
   ↓ 小学 6 年（A+6 → A+12）
初中一年级入学（A+12）
   ↓ 初中 3 年（A+12 → A+15）
中考（A+15）
```

**关键滞后**：

| 你要预测的 | 对应的生源 | 时滞 |
|---|---|---|
| 2025 年初中中考成绩 | 2009-2010 年出生、2016 年前后上小学 | ~15 年 |
| 2028 年小学入学孩子的未来中考 | 2021-2022 年出生 | 2037 年中考，滞后 ~15 年 |

**推演公式**（对目标入学年份 Y）：

- 孩子出生年 ≈ Y − 6
- 初中入学年 ≈ Y + 6
- 中考年 ≈ Y + 9
- 该批中考成绩对应的「历史参照」：当前已公布升学率 = 出生年(Y−15±1) 那批人

示例（杭州行知二小/崇德，2028 入学）：

```
2028 入学行知二小（2021-22 出生）
  → 2034 升崇德初中 → 2037 中考
历史参照：2025 崇德中考（重高≈24%）对应 2009-10 出生、2016 上小学
```

## 二、近 3-5 年升学数据采集（强制）

**必做**：目标初中给**近 3-5 年**（至少近 3 年）中考数据，不能只给 1 年。

采集维度：重高率、优高率、前三/前八/前十三上线、分配生人数与占比、毕业生规模、最高分/裸分上线等公开口径。

| 年份 | 毕业生 | 前三率 | 重高率 | 优高率 | 分配生 | 来源 |
|---|---|---|---|---|---|---|
| 2021 | | | | | | |
| 2022 | | | | | | |
| 2023 | | | | | | |
| 2024 | | | | | | |
| 2025 | | | | | | |

**口径铁律**：

- **「重高率」口径各年可能不同**（如"前八所"vs"前十三所"vs"裸考上线"），跨年对比前必须先对齐口径，对不齐的并列披露并标注。
- 官方公开数据优先；民间喜报/自媒体榜单标"非官方"。
- 新办学校（办学 < 5 年）可能只有 1-3 年数据：缺失年份写"未查到公开数据"，**不得用集团本部或其他校区成绩替代**。
- 第一届中考数据尤其重要（反映办学初期的真实水平），但也注意早期生源可能不全来自现对口小学（对口关系当年才确定，如崇德 2022 年才官宣对口行知二小/竞舟二小/浙大二附小）。

搜索关键词：

- `{初中名} 中考 重高率 优高率 2021 2022 2023 2024 2025`
- `{初中名} 中考成绩 {年份}`
- `{初中名} 分配生 毕业生`
- `{区名} 义务教育 招生 对口 初中 决策 公告`（确认对口关系确立年份）

## 三、重建「当年生源」（历史对照）

对每一条历史升学率，重建它对应的生源画像——**说明为什么那批孩子成绩好/差**：

| 维度 | 怎么查 | 对升学率的影响 |
|---|---|---|
| 出生人口 | 统计局年鉴/公报：`{区} 户籍出生人口 {年份}` | 数量：人多 → 竞争激烈 |
| 板块开发阶段 | 小区交付时间（链家小区页建成年份） | 交付初期入住率低、生源少 |
| 购房人群 | 当时板块定位（承接外溢、产业人群、高知） | 家长教育投入与生源质量 |
| 对口关系 | 教育局对口决策公告年份 | 当年生源是否全部来自现对口小学 |
| 学校阶段 | 新办/成熟/扩张期 | 师资与管理的成熟度 |

示例（杭州崇德，2025 中考 = 2016 入学批）：

- 出生：西湖区 2009 年 6,264 人 / 2010 年 7,650 人（统计局口径）
- 板块：蒋村 2009-2016 年间商品房陆续交付（西溪蝶园 2009/2012、西溪里 2012、西溪华府 2014、富越香溪 2014），2016 年时入住率爬坡
- 人群：承接未来科技城外溢 + 浙大/城西高知，商品房自住为主
- 对口：这批孩子 2016 年上小学时行知二小尚未开办（2018 开班），小学阶段对口不完全等于现在的组合

## 四、当前生源画像（你要买的这批）

对目标入学年份（如 2028）的生源做画像，与历史对比：

| 维度 | 历史（如 2016 入学批） | 当前（如 2028 入学批） | 变化方向 |
|---|---|---|---|
| 出生人口 | 西湖区 2009-10：6,264-7,650 | 西湖区 2021-22：6,492-6,870 | 数量减少 |
| 板块成熟度 | 开发中/入住爬坡 | 成熟（交付 10 年+） | 生源更稳定 |
| 学区门槛 | 概念形成初期，门槛低 | 深度回调后仍 300-500 万 | 筛选效应持续 |
| 学校阶段 | 小学尚未开办/新开 | 小学办学 8-10 年 | 更成熟 |
| 家长画像 | 高知新中产 | 高知新中产（存量置换+新购） | 大体一致 |

## 五、未来预测（数量效应 × 质量效应 × 学校效应 × 政策效应）

**不要只给一个数字**，要拆解驱动因素，分情景给区间：

1. **数量效应（分母）**：出生人口下滑 → 未来中考人数减少 → 同口径下重高/优高率上升压力小。量化：目标批次出生人口 vs 历史批次，如 2021-22 西湖区出生（~6,700/年）< 2009-10（~7,000/年），且远低于 2016-18 高峰（9,000+/年）。
2. **质量效应（分子）**：板块成熟 + 学区门槛筛选 → 生源质量不弱于历史；但需注意生源总量减少后，头部生源的绝对数量也在变少（关注"前 N 名绝对人数"而非仅比例）。
3. **学校效应**：办学年限越长、师资沉淀越深；集团化办学（名校+新校）的师资轮换是双刃剑。
4. **政策效应**：分配生比例提高（利好多数公办生）、多校划片/教师轮岗（稀释单校确定性）、民办摇号政策变化。
5. **跨年对照**：把目标批次（如 2037 中考）与历史上"出生人口最接近的批次"对照，而不是与最近一年对照。

**输出格式**（报告必含）：

| 情景 | 2037 年中考（2028 入学）重高率预判 | 依据 |
|---|---|---|
| 基准 | 24-30%（与当前持平或略升） | 生源质量相当 + 分母缩小 |
| 乐观 | 30%+ | 集团化深化 + 分配生提高 + 生源筛选加强 |
| 悲观 | <20% | 多校划片落地稀释 + 教师轮岗 + 生源绝对数量减少导致头部萎缩 |

置信度：**中-低**（政策与人口都是外生变量，10 年预测天然低置信，必须标注）。

## 六、必交付表格与引用

报告「学校与生源」章节必须包含：

1. **升学率多年表**：目标初中近 3-5 年（口径对齐 + 来源锚点）。
2. **代际传导表**：历史升学率 → 当年生源画像；当前生源画像 → 未来预判。
3. **三情景预测表**：基准/乐观/悲观 + 驱动因素拆解。
4. **引用要求**：每项数据带五要素（来源 + 真实 URL + 时间 + 口径 + 一致性）；出生人口用统计局年鉴/公报，升学数据用官方或可核验平台，全部标"非官方"则单独说明。

## 七、常见错误（本框架要防的）

- 拿最新一年升学率直接外推孩子未来（忽略 ~15 年滞后）。
- 只给 1 年升学数据（样本不足，无法看趋势）。
- 跨年比较重高率不核对口径（前八 vs 前十三 vs 裸考）。
- 用集团本部成绩替代校区成绩。
- 忽略对口关系确立年份（早期生源 ≠ 现在对口组合）。
- 只看人口数量下滑，不看板块筛选带来的生源质量。
- 把 10 年预测说得像确定结论（必须给置信度与政策情景）。
