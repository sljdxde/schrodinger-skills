# Report Template

报告要先给结论，再给证据。不要把用户逼着读完 4000 字才知道能不能买。

**产物规范：最终交付为单份自包含 HTML 报告**。SVG 走势图、引用链接、表格全部内嵌同一文件；不输出 markdown 分片、不依赖外部图片/本地路径。数据引用必须可点击溯源（见「证据引用格式」章节）。

## 开头结论

```text
# {城市}{小区/片区}购房分析

用户输入摘要：{城市、目标对象、购房目的、预算、首付比例、入学年份、决策时间}
关键假设：{用户未提供但本次分析采用的默认假设}
仍缺信息：{会影响结论置信度的缺失项；没有则写“无”}
结论：{建议买入/谨慎可买/继续观望/不建议买入}
适用前提：{自住/学区/改善/投资}
建议价格带：{总价或单价区间}
最大风险：{一句话}
下一步：{实地看房/等成交验证/换备选}
```

## 正文结构

1. 用户输入摘要和关键假设：城市、目标对象、预算、入学年份、购房目的、决策时间、缺失信息、数据截止日期。
2. 楼盘基本面：位置、产品、户型、物业、配套、优缺点。
3. 交易与价格：成交、挂牌、库存、议价、同户型样本，**含月度价格时间轴、峰值/谷值/当前值、波动幅度与样本量**。
4. 学区溢价：目标学区房与周边非学区/弱学区可比盘价格对比，拆分教育溢价和居住价值。
5. 学校与生源：对口、升学、政策、学位、学校生源和小区人口画像；目标学校**梯队评级**（第一/二/三/四梯队 + 依据，见「学区梯队评级」章节）。
6. 横向比较：2-3 个可比楼盘/片区，解释可比原因。
7. 价格预期：三情景、三时间段、置信度和关键假设。
8. 风险清单：政策、市场、流动性、学校、小区品质、家庭现金流。
9. 操作建议：买入条件、谈判抓手、放弃条件、替代方案。
10. 数据来源和局限：列出来源、时间、口径差异。
11. 学区 vs 非学区差异比较与后续走势：详见文末专章（必须包含，见下）。

## 证据引用格式（必须）

每条关键事实、数字、政策或结论都必须**可点击溯源**：

- 正文中的引用编号做成**可点击锚点**，点击跳转到文末对应引用（不要纯文本 `<sup>[N]</sup>`）。写法：
  南京 2025 年二手成交均价 19,881 元/㎡，同比 -13% <a href="#cite-1" class="cite-ref">[1]</a>。
- 文末（数据来源章节）的「参考资料」列表每项含**真实 URL**，点击在新窗口打开原始信息。`render_citations(cites)` 会自动给每条 `<li>` 生成 `id="cite-N"`，正文用 `<a href="#cite-N" class="cite-ref">[N]</a>` 即可跳转：

```html
<h2>参考资料</h2>
<!-- render_citations 生成，形如：<li id="cite-1"><a href="https://..." target="_blank">标题</a></li> -->
```

- `scripts/data_sources.py` 的 `render_citations(cites)` 生成该列表；`cites = [{"label": "标题", "url": "https://..."}]`。
- 规则：
  - 只能引用真实抓取/检索到的 URL；没拿到 URL 的，标 `未提供链接`，不得编造。
  - 同一来源多处引用可复用同一编号。
  - 政府文件、官网、平台详情页优先于转载/自媒体；低可信来源（论坛、口碑）在引用文本里注明“非官方”。

## 价格时间轴（必须）

同一小区价格是波动的，报告必须给出近 12-36 个月月度时间轴，禁止只写一个“当前均价”。按挂牌、成交两个口径分别列表：

| 月份 | 挂牌均价（元/㎡） | 挂牌样本量 | 成交均价（元/㎡） | 成交样本量 | 来源 |
|---|---|---|---|---|---|
| 2026-07 | | | | | |
| 2026-06 | | | | | |
| 2026-05 | | | | | |
| … | | | | | |

必须同时回答：

- 峰值、谷值、当前值分别是什么？分别出现在哪个月？
- 月均波动幅度约多少？近 3 / 6 / 12 / 24 / 36 个月涨跌幅分别是多少？
- 波动是成交量驱动、政策冲击、户型/楼层结构变化还是样本噪声？
- 样本不足 5 套的月份写“样本不足”，不编造精确均价。

## 走势图（必须内嵌）

同一小区价格波动必须可视化为走势图，禁止只给表格。报告须内嵌 `scripts/data_sources.py` 的 `render_timeline_chart(history)` 生成的**自包含 SVG 折线图**：挂牌均价 vs 成交均价双序列（蓝 `#2f6fed` / 橙 `#f5933b` 对比，不用红绿映射涨跌），标注峰/谷/当前值，样本量 < 5 的月份用空心点、不实线连接。SVG 零依赖，可直接嵌入 HTML 报告；转 docx 时由 html-to-docx 转图。实时预览可另生成 Chart.js 版 HTML。

生成方式：

```bash
python scripts/data_sources.py timeline --community 文鼎苑 --city 杭州 --months 36
# 结果含 svg_chart 字段，直接粘入报告
```

走势图须与上方时间轴表格数据一致；若某口径（挂牌或成交）数据缺失，图上只画存在的序列并注明。时间窗口默认 36 个月，用户另有声明时按其要求取数。

## 图表融合原则（必须，不另立图表章）

图表是辅助理解的手段，**不是独立章节**。所有图表都必须嵌入到它所对应的正文板块里，与文字、数据、表格并排或紧随其后，用图直观支撑该板块的论点；**严禁新增"更多图表 / 图表汇总"之类的独立图表章**。

按板块灵活选用图表类型（零依赖 SVG，均由 `scripts/data_sources.py` 生成，可内嵌）：

- **§2 交易与价格**：`render_timeline_chart(history)` 双序列折线（挂牌 vs 成交），与月度时间轴表格同框，展示峰/谷/当前值与跌幅。
- **§3 学区梯队评级**：`render_tier_chart([{"label","value"}])` 梯队指数对比（10=第一梯队 / 7=第二梯队 / 5=第三梯队 / 3=第四梯队），放在梯队表格旁，直观显示目标校相对头部校的位置。
- **§5/§7 学区溢价与横向比较**：`render_bar_chart([{"label","value"}])` 可比盘单价柱状图（单位元/㎡），放在溢价/横向比较表格旁，一眼看价差。
- **§8 价格预期**：`render_range_chart([{"label","low","mid","high"}])` 三情景区间图（单位 %），放在三情景表格旁，用区间条呈现乐观/基准/悲观的变动中枢。

排版要点：图表用 `.chartbox` 容器（卡片化、圆角、配文末 caption），宽度随容器自适应（`svg{width:100%;height:auto}`）；caption 写清数据口径与来源编号，避免图与文脱节。

## 学区 vs 非学区差异比较与后续走势（必须专章）

涉及学区房时，报告**必须**在结尾前给出这一章：把"学区房贵多少"和"以后还会不会更贵/跌"讲清楚。可用 `scripts/data_sources.py` 的 `compare_school_vs_nonschool` 输出直接填充。

### 学区 vs 非学区差异比较表

| 维度 | 目标学区房（商品房口径） | 周边非学区/弱学区可比盘 | 差值 | 置信度 |
|---|---|---|---|---|
| 平均挂牌单价（元/㎡） | | | | |
| 平均成交单价（元/㎡） | | | | |
| 学区溢价率 | | | | |
| 溢价主要来自 | 学校确定性/入学门槛/口碑 | 居住价值为主 | | |
| 回迁房影响 | 单列，不混入溢价计算 | — | | |

> 学区侧均价用**商品房口径**（剔除回迁房/安置房），否则会被低价回迁房拉偏；回迁房单独列出其挂牌价与居住/流动性短板。

### 后续房价走势分析

结合 `forecasting-framework.md` 三情景，重点回答：

1. **溢价可持续 / 收窄 / 反转**：当前学区溢价在未来 1-3 年、3-10 年分别怎么走。
2. **驱动变量**：少子化（出生人口约 6 年传导到小学入学）、教育均衡化（多校划片、教师轮岗、学位预警）、近 12-36 个月量价动量。
3. **触发信号**：连续 N 月成交量恢复 / 议价空间收窄 / 学区政策落地 / 出现低于某价位的成交 —— 作为"买入 or 放弃"的观察指标。
4. **结论**：学区房相对非学区的后续相对价值判断，并给出置信度。

## 学区梯队评级（涉及学区时必须）

给出目标学校在**同城范围内的梯队定位**，让用户一眼看懂“这是不是好学区”。框架见 `references/school-tier-reference.md`。

| 梯队 | 定位 | 典型特征 | 对房价含义 |
|---|---|---|---|
| 第一梯队 | 全市/区域公认头部名校 | 历史名校或强教育集团核心校，公开升学表现稳定优秀，学位高度紧张 | 高学区溢价，抗跌但政策风险最敏感 |
| 第二梯队 | 优质公办/强集团校 | 区级重点、名校集团校区，口碑好，学位较紧张 | 中等溢价，稳健 |
| 第三梯队 | 普通公办 | 对口正常、质量一般，无突出口碑 | 学区溢价低，主要靠居住价值 |
| 第四梯队 | 一般/待提升或新建校 | 新办未成熟、历史口碑弱 | 无学区溢价逻辑 |

要求：

- 必须标注**评级依据**（官方文件、集团化关系、可核验升学表现、学位紧张度、生源结构），并给出至少一个同城头部学校作参照（如南京鼓楼拉小/力小/琅小、玄武北小等，见参考文件）。
- 公开证据不足时写“未评级（证据不足）”，不得仅凭自媒体口碑定梯队。
- 非官方升学数据必须标注“非官方，仅作口碑参考”。

示例（南京）：

| 学校 | 梯队 | 依据 |
|---|---|---|
| 拉萨路小学（鼓楼） | 第一梯队 | 市属/区属公认头部，学位预警常见，公开报道升学表现稳定 |
| 北京东路小学（玄武） | 第一梯队 | 传统名校，集团化办学 |
| 晓庄小学（栖霞） | 第三梯队 | 2019 新办、晓庄学院附小集团，非头部，无强口碑 |
| 伯乐中学（栖霞） | 第三梯队（待官方核验） | 区属公办，第三方称“全区前列”，非官方 |

## 评分表

| 维度 | 权重 | 评分 | 说明 |
|---|---:|---:|---|
| 居住品质 | 20% | | 产品、物业、配套、通勤 |
| 学校确定性 | 20% | | 划片、政策、学位规则 |
| 学校质量与生源 | 20% | | 升学、口碑、生源结构 |
| 市场流动性 | 15% | | 成交、挂牌、换手 |
| 价格安全边际 | 15% | | 跌幅、议价、可比价 |
| 长期人口与供需 | 10% | | 出生、流入、库存 |

评分解释：

- 8-10：价值稳固，适合明确自住需求。
- 6-8：有支撑但需价格安全边际。
- 4-6：风险较高，除非价格明显补偿。
- 4 以下：不建议以学区或投资逻辑买入。

## 购买建议写法

### 建议买入

必须同时满足：

- 价格不高于近期同户型成交中位数，或有明确装修/楼层优势。
- 学校确定性可核验，目标入学年份政策风险可控。
- 家庭现金流能承受 12-24 个月价格不涨或小幅下跌。

### 谨慎可买

适用于自住价值强但市场仍弱的情况。给出谈判价、可接受溢价和止损条件。

### 继续观望

给出观察指标，例如连续 2-3 个月成交量恢复、议价空间收窄、学区政策落地、目标户型出现低于某价位的成交。

### 不建议买入

说明根因：学校不确定、流动性弱、价格仍高估、居住品质无法托底或家庭现金流压力过大。必须给替代方向。

## HTML 视觉规范（橄榄手记风格）

报告按「橄榄手记」风格排版：**纸感、留白、橄榄绿点缀、清晰优先**。所有样式内联在 `<style>` 中（单文件自包含）。

### 设计令牌（CSS 变量）

```css
:root{
  --paper:#f6f3ec;      /* 奶油纸底 */
  --card:#fffdf8;       /* 卡片纸面 */
  --ink:#2f2a24;        /* 墨色正文 */
  --sub:#8a8272;        /* 次级文字（橄榄灰） */
  --olive:#5c6b3c;      /* 橄榄绿主色 */
  --olive-soft:#e8ecd9; /* 橄榄浅底 */
  --accent:#b45309;     /* 结论强调（琥珀） */
  --line:#e4ddcd;       /* 分隔线 */
  --warn:#f6e9e3;       /* 警告底 */
  --warn-ink:#9a3412;
}
```

### 排版要点

- 背景用 `--paper`，正文卡片用 `--card`，圆角 12–14px、柔和阴影，正文墨色 `--ink`。
- 标题：衬线感（`Georgia, "Songti SC", "SimSun", serif`），一级标题橄榄绿，章节标题（h2）加细下划线。
- 结论卡（verdict）：橄榄浅底 `--olive-soft` 或琥珀底，大字号结论句。
- 引用链接：橄榄绿下划线，悬停加深；`<sup>` 上标编号橄榄色。
- 表格：表头橄榄浅底 `--olive-soft`、圆角、斑马纹可选；数字列右对齐。
- 警告框：`--warn` 底 + `--warn-ink` 文字。
- 页脚：小字号、橄榄灰，注明生成时间与免责声明。
- 保持高对比度与可读性（清晰 > 装饰）；勿用红绿表达涨跌（走势图沿用蓝 `#2f6fed` / 橙 `#f5933b`）。
