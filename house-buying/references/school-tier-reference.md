# School Tier Reference — 学区梯队评级框架

为「这所学校到底算不算好学区」提供统一、可核验的评级口径。报告涉及学区时必须给出梯队定位与依据，证据不足时标注「未评级」。

## 四梯队定义

| 梯队 | 定位 | 典型特征（可核验信号） | 对房价含义 |
|---|---|---|---|
| 第一梯队 | 全市/区域公认头部名校 | 历史名校或强教育集团核心校；公开报道/官方文件可查的稳定升学表现；学位预警/落户年限要求常见 | 高学区溢价，抗跌；对多校划片等政策最敏感 |
| 第二梯队 | 优质公办 / 强集团校区 | 区级重点、名校集团校区/分校；口碑好、班级规模正常、学位偏紧 | 中等溢价，较稳健 |
| 第三梯队 | 普通公办 | 对口正常、质量一般，无突出口碑与公开升学亮点 | 学区溢价低，价格主要由居住价值支撑 |
| 第四梯队 | 一般 / 待提升 / 新建未成熟 | 新办未出成绩、历史口碑弱、生源不稳定 | 无学区溢价逻辑 |

## 评级依据（必须来自公开证据）

按证据强弱加权，最终给出梯队 + 一句依据：

1. 官方定位：教育局文件、学校官网办学介绍、集团/校区关系（高可信）。
2. 升学表现：公开可核验的中考/升学数据或主流媒体正式报道（高/中可信）；民间榜单、论坛口碑（低可信，只能作参考并标注「非官方」）。
3. 学位紧张度：学区预警、落户年限要求、学位占用规则（中可信）。
4. 生源结构：对口小区构成、房价门槛、租售比（中可信）。
5. 师资与班额：官方公开的骨干教师比例、班级规模（中可信）。

规则：

- 梯队是**同城相对**概念，跨城不可直接比（北京“普小”可能强于小城“名校”）。
- 每个评级至少给一个**同城头部参照**，说明差距（例如：栖霞晓庄小学 vs 鼓楼拉萨路小学）。
- 只能按公开证据评级；证据不足写「未评级（证据不足）」。不得凭单条自媒体口碑定梯队。

### 北京 / 上海 / 广州 / 深圳（一句话口径）

- 北京：东西城、海淀“六小强”体系为第一梯队，郊区/新建校普遍第三梯队起。
- 上海：徐汇、静安、黄浦等传统强区名校为第一梯队；临港等新片区多为第三梯队新建校。
- 广州：越秀、天河头部公办（华附系、省实系等）为第一梯队。
- 深圳：四大/八大名校及集团核心校为第一梯队；关外新校多为第三梯队。
- 以上均需联网核验当年教育局文件与公开升学信息。

## 未评级处理

无法获得可靠公开证据时：

- 报告中写「梯队：未评级（证据不足）」，并列出缺什么（无官方办学信息/无公开升学/无口碑一致性）。
- 不得用「第一梯队潜力股」等无依据话术；可写「待学校出成绩后再评估」。

## 对分析流程的影响

- 梯队结论进入报告「学区梯队评级」专章（见 report-template.md）。
- 梯队影响评分表「学校质量与生源」维度（第一梯队 8-10、第二梯队 7-8、第三梯队 5-6、第四梯队 ≤5 参考）。
- 梯队结合溢价分析：第一/二梯队才有显著「学区溢价」讨论价值；第三/四梯队溢价应归因于居住价值。
