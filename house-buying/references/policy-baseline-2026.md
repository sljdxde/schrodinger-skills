# 2026 学区房政策基线快照

> 数据载体：`scripts/city_policy.json`（逐城结构化，由 `python scripts/data_sources.py policy --city <城市>` 读取）
> 用途：供 `school-cohort-analysis.md`（生源代际传导）与 `forecasting-framework.md`（价格预测）将 **2026 政策冲击设为默认高权重情景**；报告中显式提示「2026 为政策落地元年，历史升学率外推置信度进一步降低」。
> 更新机制：随自动更新机制年度刷新（招生季 4-5 月重跑核验），避免用过时期基线下结论。

## 一、2025-2026 政策巨变（step-change，非渐变）

这是本轮优化的核心背景——学区房「买一套=锁名校」的确定性支柱被系统性削弱：

1. **全国强制多校划片**：教育部要求 **2026 年起全国城区义务教育全面推行多校划片 + 电脑派位**。「买房对口名校」逻辑失效，同一套房产未来对应学校从「确定」变「概率」。
2. **教师轮岗全国推行**：2026 两会明确年底前县域集团化办学全覆盖，教师满 9 年必须轮岗，城区优质校年轮岗 ≥15%、骨干 ≥20%。名校师资优势被稀释。
3. **户籍与权益脱钩**：国发〔2026〕11号《关于推行常住地提供基本公共服务的实施意见》。已出现：张家港取消房产与学位关联、呼和浩特试点取消户籍限制、深圳 530 学位全摇号、租购同权。
4. **市场已反应**：北京海淀学区房 2025 同比约 −35%、深圳部分腰斩、杭州超七成学区房门槛回落 150 万以下。
5. **少子化传导**：2017 新生 1723 万 → 2025 年 792 万；2025 小学招生比 2023 峰值少 22%。入学需求长期下行，学区溢价的需求底座松动。

> **对分析的影响**：cohort 与 forecasting 已内置「多校划片/教师轮岗/少子化」逻辑（方法论正确）。但在 **2026 政策基线**下，应：
> - 将「学区确定性」这一支柱的**权重下调**；
> - 将「政策风险情景」的**置信度/权重上调**；
> - 报告中显式标注「历史升学率对未来的外推置信度进一步降低，2026 为政策落地元年」。

## 三、使用方法

```bash
# 读取某城 2026 政策基线（供 cohort / forecasting 设定情景权重）
python scripts/data_sources.py policy --city 杭州

# 读取学区划片源与预警源（见 city_sources.json 的 school_district / enrollment_alert 字段）
python scripts/data_sources.py sources --city 杭州
```

分析时：

- **cohort 分析**：在「政策效应」因子中，将 2026 多校划片 + 教师轮岗 + 户籍脱钩作为**已发生的高置信冲击**，而非可选情景；三情景中「政策冲击持续」权重上调。
- **forecasting**：价格预测基准情景的中枢应较历史趋势**下移**，悲观情景须含「学区确定性进一步丧失导致溢价收缩」路径；明确提示政策风险为首要下行风险。
- **报告呈现**：在「学区确定性」与「政策风险」章节显式引用本基线（带 `city_policy.json` 来源与访问日期），并提示用户「2026 政策落地元年，结论随当年公告动态调整」。
