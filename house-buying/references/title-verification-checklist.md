# 学位占用 / 落户年限 用户自查清单与合同保护模板

> 配套：`scripts/city_policy.json`（2026 政策基线）、`references/policy-baseline-2026.md`
> 适用：凡涉及学区、孩子入学的购房分析，必须在出报告前把本清单的「买前自查」作为结论的强制前置提醒；报告「学区确定性」章节须提示用户执行线下核验。

## 核心认知（先讲清，避免误判）

1. **学位占用与户籍无关，只与「房产使用记录」挂钩**：同一套房子，前一个业主的孩子用该地址入了学并占用学位，后买家即便已落户也可能被挡。务必查「该房产的学位占用状态」，而非仅看自己是否落户。
2. **落户年限（房户一致）是「入学门槛」而非「学位占用」**：多数城市要求「房户一致 + 落户满 N 年」才优先录取；年限不足会被统筹（多校划片/摇号）。这条只能研究城市规则，无法在购房前由 skill 核验「该房是否满足年限」，需用户凭自身落户时间自评或线下咨询。
3. **线上查询结果有效期通常约 30 天**：政务 App 的「学位占用 / 五年一户 / 房产曾用查询」结果随交易与入学季变动，签约前务必重新核验，不要把半年前的截图当依据。
4. **学位占用无法由 skill 机读**：这是政务 App 的**个人隐私查询**（浙里办 / 随申办 / 京通 等），skill 不擅自突破登录墙。本清单把「研究规则」升级为「用户可执行的避坑流程」。

## 买前 3 步自查（强制提醒用户）

### 第 1 步：查「学位是否被占用」

| 城市/省 | 查询入口（政务 App 或官网） | 查什么 |
|---|---|---|
| 浙江（杭州/宁波/绍兴等） | 浙里办 →「e房通 / 房屋租售 / 教育码→房产曾用查询」 | 该房产历次用于入学的记录、学位是否锁定 |
| 上海 | 随申办 →「我的不动产 / 五年一户查询」 | 该地址近 5 年是否已被用于入学 |
| 北京 | 北京通 / 各区教委入学服务平台 | 该地址学位占用与多校划片派位结果 |
| 广东（深圳/广州/佛山/珠海） | 粤省事 / 各市义务教育招生平台 | 房产对应学位占用、地段生资格 |
| 江苏（南京/苏州/无锡等） | 苏服办 / 各市招生平台 | 六年一学位占用查询（部分区） |
| 其他城市 | 省级政务 App + 区教育局基础教育科 | 以当年教育局公告口径为准 |

> 线上查不到或显示「未提供」时，**不要默认「无占用」**，必须走第 2 步线下核验。

### 第 2 步：线下核验（最稳妥）

- 对口学校**教务处**或**区教育局基础教育科**：携带房产证/购房合同，口头或书面确认该地址当前学位占用状态、对口学校、当年录取排序规则。
- 要求对方明确：**「该房产对应学位在哪一年度可被再次使用」**（即锁定几年、何时释放）。

### 第 3 步：合同条款保护（签约前必做）

在《房屋买卖合同》中增加「学位占用声明与赔偿」条款（模板见文末）。**没有这条，买到被锁定学位的二手房几乎无法追责。**

## 《学位未被占用声明书》+ 赔偿条款模板

> 以下为可直接复制到合同的条款，方括号内容按实际填写。签约前由卖方签署声明书作为合同附件。

**附件：学位占用情况声明书（卖方签署）**

> 本人（卖方）郑重声明：截至本声明签署之日，坐落于【省市区 小区 栋 号】的房产，其对应义务教育学位【未被占用 / 已被占用，预计于【YYYY】年【MM】月释放】。
> 该房产对口小学为【___】，对口初中为【___】；本人已知悉当地「【六年一学位 / 五年一户 / 其他】」政策。
> 若上述声明与事实不符（含签约后、过户前被新占用），本人承担以下责任（见本合同第【N】条）。
>
> 卖方（签字）：__________ 身份证号：__________ 日期：__________

**合同赔偿条款（第 N 条）**

> 卖方承诺本合同标的房产对应义务教育学位未被占用（或已如实披露占用及释放时间）。若因卖方隐瞒导致买方子女无法按预期入读对口学校，卖方应：
> 1. 无条件配合买方解除合同、退还全部已付房款及中介费、税费；或
> 2. 按合同总价【___%】向买方支付违约金，并赔偿买方因此产生的包括但不限于择校费、补习费、租房成本等直接损失；
> 3. 买方有权从尾款中直接扣留相应金额作为履约担保，直至学位状态经官方核验清晰。
> 本条款独立于合同其他条款，不因合同解除而失效。

## 报告中的呈现要求

- 「学区确定性」章节必须含一段**醒目提示框**：告知用户「学位占用 / 落户年限满足度需自行线下核验，本报告仅研究城市政策规则，不构成对该房产具体状态的确认」。
- 若分析结论高度依赖「学位未被占用」假设，须在「关键假设」与「风险提示」中显式标注，并给出上述 3 步自查路径。
- 合同模板作为报告附录「避坑工具」提供，注明「以当地房管与教育部门最新口径为准，建议由执业律师复核」。

## 城市落户年限规则（研究要点，非核验结论）

仅作规则研究参考；具体满足度需用户凭自身落户时间自评或线下咨询区教育局：

- **北京**：房户一致 + 实际居住；部分区（西城/东城）多校划片，落户年限影响排序。
- **上海**：公民同招 + 五年一户（部分区如静安、徐汇）；人户一致优先。
- **杭州**：房户一致优先；部分区执行「六年一学位」，落户时间影响一表生排序。
- **深圳**：租购同权 + 积分入学；户籍/房产/社保均计积分，不唯房产。
- **南京/苏州/无锡等**：多数区「六年一学位」；房户一致为地段生前提。
- **其他城市**：以当年教育局招生公告为准，分析时联网核验最新规则。

> 红线：本清单所有内容仅为「避坑流程引导」，不替代政务 App 查询与线下核验；skill 不得宣称已核验具体房产的学位/落户状态。
