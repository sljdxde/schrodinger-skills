# ADR-0005 五级数据源体系 + 单一维度展开 + 引用防伪

- 状态：已采纳（Proposed → Accepted）
- 日期：2026-08-12
- 版本：house-buying 1.2.0（minor：加能力，脚本 API 向后兼容）

## 背景 (Context)

用户要求全面重构 house-buying 的数据获取能力，核心目标为大幅提升**数据获取的广度与准确性**，四点要求：

1. **数据源扩充与分级**：头部平台（贝壳/链家/我爱我家）为核心；政务网/住建局/自然资源局（不动产登记）为官方佐证；浙里办/随申办/京通等政务 App 补充；诸葛找房/安居客/房天下/58同城交叉验证。
2. **单一维度展开**：先从「房价」维度（挂牌/成交/环比/同比）建立完整数据链路，再逐层扩展成交量/供需比/土地出让/学区政策/人口流动/信贷环境。
3. **引用佐证与防伪**：每项数据必须携带来源链接、发布时间、数据口径；多源冲突按「时间最新 > 口径最权威 > 最接近一手」裁决。
4. **数据完整性**：最大化数据源数量与覆盖地域，同一指标多源交叉并标注一致性。

此前技能为「核心双源（贝壳系+我爱我家）」+ 31 城注册表（ADR-0001），无维度展开框架，引用仅要求 URL。

## 决策 (Decision)

### 1. 五级数据源体系（T0-T4）

- **T0 核心平台**（强制双源）：贝壳系（贝壳/链家）、我爱我家 —— 挂牌/成交/带看/房源量主证据。
- **T1 官方佐证**：住建局/网签平台、自然资源局/不动产登记中心、统计局、教育局 —— 冲突裁决最高权重。
- **T1.5 城市本地高频源**：杭房数研类 —— 接近网签口径，杭州等城市补充。
- **T2 政务 App/小程序**：浙里办/随申办/京通/粤省事等 + 城市官方小程序 —— 政策与交易数据补充，封闭生态不突破登录墙。
- **T3 交叉验证**：诸葛找房/安居客/房天下/58同城 —— 只做交叉比对，不单独支撑结论；58同城可信度最低。
- **T4 舆情**：自媒体/论坛/业主群 —— 线索级。

脚本 `data_sources.py` 新增 4 个 T3 适配器（诸葛找房/安居客/房天下/58同城），所有源注册 `tier` 分级字段；`fetch` 结果携带 tier。

### 2. 单一维度展开策略

新增 `references/dimension-network.md`：房价为**唯一必做维度**（月度时间轴 + 环比/同比/N月涨跌幅 + 带看/房源量），其余 6 维度（成交量/供需比/土地出让/学区政策/人口流动/信贷环境）按用户诉求逐层展开；脚本内置 `DIMENSION_FRAMEWORK` 与 `dimensions` 子命令输出各维度字段/来源/展开条件；新增 `compute_mom_yoy()` 计算环比/同比/N月涨跌幅（**按日历月差，缺月不编造**）。

### 3. 引用五要素防伪

每项被引用数据必须携带：**来源 + 真实 URL + 发布时间/访问时间 + 数据口径 + 一致性程度**。`render_citations()` 支持 date/caliber/consistency 元数据字段，渲染为 `<span class="cite-meta">[...]</span>`；数据源冲突按「时间最新 > 口径权威 > 最接近一手」裁决，差异 ≤5% 视为一致，>5% 并列披露，硬冲突标「存疑/来源冲突」。

### 4. 数据完整性

`city_sources.json` 从 31 城扩至 **45 城**（+深圳/宁波/青岛/厦门/大连 5 计划单列市 + 苏州/无锡/东莞/佛山/温州/泉州/南通/嘉兴/珠海 9 强地级市），**新增城市 gov URL 均经 2026-08 联网核验**，核验不到的只登记平台名不写 URL；同城同一指标多源交叉并标注一致性。

## 后果 (Consequences)

- 数据获取广度显著提升：45 城有明确 gov 取数指引，T0/T3 全国源 + T1/T2 城市源形成完整链路。
- 报告防伪能力加强：引用五要素强制，编造 URL/默认口径被视为返工项。
- 脚本 API 向后兼容：`render_*`、`school/communities/fetch/timeline/sources` 命令不变，工作区既有报告生成器不受影响；新增 `dimensions` 命令与 `compute_mom_yoy()` 为增量。
- 维护成本上升：45 城注册表需随政策/平台变更更新；gov URL 变动需重新核验。

## 备选 (Alternatives)

- 保持双源 + 31 城（最小改动）：不满足用户"大幅提升广度与准确性"的核心诉求，否决。
- 一次性展开全部 7 维度（贪多求全）：每个维度浅尝辄止、缺数据凑数，违反"先查证据"原则，否决。
- 注册表新增城市直接编造 gov URL：违反防伪铁律，否决；已改为逐城联网核验。
