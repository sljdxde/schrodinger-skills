# ADR-0002 首付比例改为必填、去掉首套/二套追问

- 状态：已采纳（Accepted）
- 日期：2026-08-11

## 背景 (Context)

原 intake 把"首套/二套、首付、贷款、月供上限"打包为**可选**字段"房票/贷款约束"，默认可"未指定"。用户两点诉求：（1）上次已嫌"首套/二套"追问啰嗦；（2）明确要求"用户的首付比例，要能够自己输入，是必填项"。

## 决策 (Decision)

- **删除** intake 中的"首套/二套"问题。
- **新增必填字段**：`首付比例（用户填写实际百分比，如 30%）`。
- **新增可选字段**：`月供上限 / 贷款额度（可选）`——用于结合预算判断现金流可行性。
- 报告侧基于"声明城市 + 首付比例"**提示**该比例是否符合当地首套 / 二套政策，**不在 intake 追问**首套二套。

## 后果 (Consequences)

- 提问更精简，契合用户上次的不满。
- 失去 intake 阶段对"限购 / 限贷资格"的自动判断；缓解：报告里用城市政策提示替代，且首付比例本身已能驱动现金 / 月供计算。
- 首付比例由用户填实际值，比"首套/二套"推断更贴近其真实资金结构。

## 备选 (Alternatives)

- 保留首套/二套并自动建议首付比例：信息更全但多一问，用户已表露不想被问。
- 首套/二套与首付比例都必填：信息最全但最啰嗦，否决。
