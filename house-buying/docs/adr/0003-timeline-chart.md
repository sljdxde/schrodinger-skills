# ADR-0003 价格时间轴走势图（渲染样式）

- 状态：已采纳（Accepted）
- 日期：2026-08-11

## 背景 (Context)

报告侧已强制要求"月度价格时间轴"表格，但用户明确要求生成真正的**月度走势图**，并强调"图表生成样式很重要，好好思考怎么生成"。纯表格表达波动 / 峰值 / 谷值不直观。

## 决策 (Decision)

在报告里内嵌一张**自包含 SVG 折线图**，由脚本从 `history` 数据生成：

- **双序列**：挂牌均价（蓝 `#2f6fed`）、成交均价（橙 `#f5933b`）；可选底部叠加成交量柱（灰）。
- **标注**：峰值 / 谷值 / 当前值用特殊标记 + 数值；浅色带标出波动区间（均线 ± 1σ）。
- **样本规则**：当月样本量 `count < 5` 用空心点 + 虚线，不实线连接，避免误导。
- **配色避坑**：不用红 / 绿映射涨跌（房价涨跌不宜套股市"红涨绿跌"语义），用蓝橙对比 + 文字标注方向。
- **零依赖**：纯 SVG（中文标签、`YYYY-MM` 横轴、元/㎡ 纵轴），viewBox 约 720×300，移动端可读；可嵌入 HTML 报告，转 docx 时由 html-to-docx 转图。
- **交互预览**：另生成 Chart.js 版 HTML（仅供实时预览，不入仓库）。

脚本新增 `render_timeline_chart(history, kind=...) -> svg`，并在 `report-template.md` 增加"走势图"章节要求。

## 后果 (Consequences)

- 趋势可读性大幅提升，且图随数据自动生成、可版本化（SVG 是文本）。
- 需实现 SVG 生成函数（纯 stdlib，不引入 matplotlib/plotly 等重依赖）。
- 转 docx 依赖 html-to-docx 对 SVG/inline image 的支持；若不支持则回退为"表格 + 图片导出"。

## 备选 (Alternatives)

- matplotlib PNG：需 numpy/matplotlib，二进制不便入库、环境依赖重，否决。
- mermaid 折线：表现力弱、标注能力差，否决。
- 纯表格：用户明确不要，否决。
